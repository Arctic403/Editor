RIFTCITY EDITOR AI — CLOUDFLARE SETUP

This project now uses ONE Cloudflare Worker for both the editor and the AI bridge.

DEPLOY FROM THE REPOSITORY ROOT.
The root wrangler.toml deploys a Worker named: editor

Bridge URL example:
https://editor.YOUR-WORKERS-SUBDOMAIN.workers.dev

Do not add /health or /api/ai/run to the Bridge URL.
The editor adds those paths automatically.

Cloudflare Worker secrets:
- OPENAI_API_KEY (required)
- AI_APP_TOKEN (recommended; enter the same value in the editor's Private app token field)

Expected routes after deployment:
GET  /health       -> JSON success
POST /api/ai/run   -> AI bridge
GET  /             -> editor UI

See AI_WORKER_SETUP.md for details.
